员工维权的三个底层原则

遇到劝退、欠薪、加班不给加班费、无故调岗、试用期任意辞退……第一反应别情绪化，先记住三条原则：

  1. 留证据：劳动合同、工资条、考勤记录、聊天记录、邮件、录音（劳动场所自己参与的谈话录音合法）。HR 一对一谈话务必同步录音。
  2. 不主动辞职：HR 暗示「主动提辞职、好聚好散」是最大陷阱——主动辞 = 放弃 N / 2N 经济补偿 + 失业金。除非确认是协商解除（公司付补偿），否则书面拒绝。
  3. 走劳动仲裁：劳动争议仲裁完全免费、流程比想象中简单（线上提交即可），仲裁裁决书是法院强制执行的依据。

本目录精选 30 条实战话术 + 真实案例，按 在职阶段 / 离职阶段 / 通用知识 分组，覆盖加班工时、工资补偿（N / N+1 / 2N）、试用期、HR 话术、调岗降薪、社保公积金、工伤病假、仲裁流程等场景。多数条目附可一键复制的邮件 / 通知函 / 仲裁材料模板。

所有劳动法话术 / 案例完整列表

共 30 条实用条目，覆盖在职、离职、加班工时、工资补偿、试用期、HR 话术、调岗降薪、社保公积金、工伤病假、仲裁流程等场景。

  1. 公司想让我"自愿离职"——别签离职书，这样回应

    HR 暗示主动辞职"好聚好散"？陷阱——等于放弃 N 补偿金 + 失业金。书面拒辞 + 要求公司给书面解除通知。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  2. "明天起你不用来了"——当场怎么应答

    公司突然让你回家、给 N 想打发？这是变相违法解除，应主张 2N。当场拒签 + 不停履职 + 24h 内邮件复述对方说辞。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  3. 拒绝单方调岗 / 降薪——书面回复模板

    公司单方面通知调岗或降薪？合同变更必须双方协商一致。不签同意不生效，强制执行可视为违法解除主张 2N。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  4. 协商解除：拒签 N，争取 N+1 / 2N 的谈判话术

    公司给 N 让你走？很多场景实质是违法解除应给 2N，至少 N+1。本话术教识别 5 种解除类型 + 分阶段谈判。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  5. 工资被拖欠——书面催讨函

    工资当月超期未发或少发？先发书面催讨函（为后续仲裁留证据），1 年内可投诉劳动监察大队或申请仲裁。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  6. 未签劳动合同——主张双倍工资差额发函

    入职超过 1 个月未签书面合同？自第 2 个月起每月可主张双倍工资差额（最多 11 个月，3 年时效内有效）。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  7. 加班费拖欠——书面催讨

    有加班记录但公司不发加班费、强制调休不补、年假不结算？60 日内仲裁。关键举证：钉钉/微信群里领导让你加班的截图。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  8. 试用期被辞退——要求书面理由的话术

    试用期不是"白用期"。辞退必须证明"不符合录用条件"。HR 凭主观感受辞退是违法解除，可主张 2N（试用期为 1 个月工资）。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  9. 准备申请劳动仲裁——告知公司的发函

    走仲裁前最后一步催告函。HR 看到正式法律文书往往立刻转变态度——很多公司宁可和解也不愿熬 60 天仲裁。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  10. 要求补缴社保 / 公积金的申请

    公司没缴或少缴社保？"自愿放弃"协议无效。先内部书面申请，不补就投诉 12333 / 社保稽核。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  11. 🧮 N / N+1 / 2N 怎么区分？

    员工最易混淆的三个数字：N = 协商解除；N+1 = 代通知金；2N = 违法解除赔偿。一张表识别公司给 N 时是否实际应给 2N。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  12. 🧮 加班费计算公式

    月计薪天数是 21.75（不是 22 也不是 30）。工作日加班 ×1.5，周末 ×2，法定节假日 ×3。常见误区："工资含加班费"多无效。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  13. ⚖️ 仲裁前置 + 时效全清单

    劳动争议必须先仲裁后起诉。一般时效 1 年；拖欠工资从离职日起算 1 年（在职期间不消失）。仲裁完全免费、可不请律师。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  14. 📋 仲裁举证清单（带什么去）

    仲裁要带：合同 + 12 月银行流水 + 工资条 + 解除通知 + 聊天记录。关键认知："解除合法"、"我不胜任"公司才是举证方。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  15. 🛡️ "自愿放弃社保"协议是无效的

    任何"自愿放弃社保"协议都无效。即使签了字，公司仍要补缴 + 你还可主张未缴损失。已签协议反而是公司过错的证据。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  16. 🆕 试用期"防坑"全清单

    试用期最长能多久？工资底线？解除条件？同一员工只能约定一次。覆盖 7 个高频陷阱 + 实战建议。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  17. 🏥 工伤认定全流程：从受伤到拿到赔偿的 5 步

    工伤不是单位说了算，是社保局认定的。5 步：及时就医留证 → 单位 30 日内申请 → 员工 1 年内可自主 → 60 日认定 → 领赔偿。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  18. 🏥 病假工资底线（不得低于当地最低工资 80%）

    病假期间公司必须支付病假工资，底线是当地最低工资 × 80%。按工龄发 60-100% 的本人工资，医疗期内不能解除合同。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  19. 🏥 老板拒绝配合工伤认定——员工单方申请

    工伤后老板不给申请、不承认劳动关系、想"私了"？员工可自己单方申请工伤认定，时效 1 年。给完整申请包模板 + 施压函。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  20. 🏥 工伤赔偿金清单（医疗费 / 停工留薪 / 伤残补助）

    工伤能拿哪些钱：医疗费 + 停工留薪期工资（按原工资）+ 一次性伤残补助金（1-10 级 7-27 个月）+ 解除时一次性补助。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  21. 🤰 怀孕期被解雇——三期违法解除应得多少

    三期 = 怀孕 + 产期 + 哺乳期（至婴儿满 1 岁）。三期内公司不得无故解除，违法解除应给 2N + 三期工资 + 生育津贴差额。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  22. 🤰 产假工资 / 生育津贴怎么算（差额谁补）

    产假不发"工资"，由生育保险发"生育津贴"。法定 98 天 + 各地奖励 60-188 天。津贴 < 产前工资？差额公司必须补。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  23. 🤰 哺乳期被调岗 / 降薪——拒绝模板

    产假复工后被调岗 / 降薪 / 取消哺乳时间？变相逼迫离职，违反《女职工劳动保护特别规定》。给完整书面回复模板。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  24. 📚 【案例】996 互联网员工，靠什么证据拿到 5.4 万加班费

    化名小李，互联网中厂前端 3 年 996，靠钉钉打卡 + 工作群截图 + GitLab commit，仲裁拿到 5.4 万（受 1 年时效限制）。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  25. 📚 【案例】试用期被"绩效差"开除，没明示录用条件，拿到 2N

    化名小张，运营专员，HR 以"绩效差"开除。offer 没明示录用条件 → 举证倒置，公司败诉。最终拿 2N + 工资差额共 1.43 万。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  26. 📚 【案例】怀孕 5 个月被裁，公司给 N+1，最终拿到 2N + 生育津贴

    化名小王，怀孕 6 个月被"业务调整"裁员，公司给 N+1（3.6 万）。员工坚持仲裁，最终拿 26.95 万（公司原报价的 7.5 倍）。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  27. ⏰ 周末团建 / 早晚开会算加班吗？

    强制团建 / 不去扣绩效 / 早晚规律性会议 → 算加班。自愿娱乐 / 通勤不算。关键举证：能证明这是"公司安排"还是"自愿"。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  28. ⚖️ 竞业限制条款——什么情况下无效 / 怎么破除

    竞业限制 4 个无效红线：①不付补偿 ②超过 2 年 ③范围过宽 ④违约金过高。普通员工不能签。三个月不发补偿员工可单方解除。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  29. 💰 公司倒闭 / 老板跑路——员工追欠薪 4 步走

    员工追欠薪 4 步：①24h 内收集证据 ②12333 投诉 + 集体仲裁 ③法院强制执行（含起诉股东）④巨额可刑事报案。第一周决定 80% 的结果。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm

  30. ⚖️ "末位淘汰" 是合法的吗？被淘汰的应得 2N

    末位淘汰不是合法解除事由——"最末位"≠"不胜任"。最高法明确：以末位为由解除属违法解除，应给 2N。胜诉率 90%+。

    https://www.gov.cn/banshi/2005-08/05/content_20700.htm
